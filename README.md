# ESP8266 Accident Detection System

An IoT-based accident detection prototype using ESP8266 NodeMCU,
MPU6050 accelerometer, GPS and Telegram.

## Features

- Real-time acceleration monitoring
- Accident detection at 12 m/s²
- Buzzer warning
- 10-second accident cancellation
- Push-button cancellation
- GPS coordinates
- Accident date and time in IST
- Telegram emergency notification
- Google Maps location
